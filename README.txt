BORACONSTRUIR.COM — PDV
VERSÃO PARA ANDROID + iOS

A versão funciona como aplicativo web instalável (PWA).

iPhone/iPad:
1. Publique os arquivos em um endereço HTTPS.
2. Abra o endereço no Safari.
3. Toque em Compartilhar.
4. Escolha "Adicionar à Tela de Início".
5. Abra o ícone Boraconstruir PDV pela tela inicial.

Android:
1. Abra o endereço HTTPS no Chrome.
2. Escolha "Adicionar à tela inicial" ou "Instalar aplicativo".

O leitor de código de barras pela câmera depende do suporte do navegador e das permissões de câmera.
Os dados do PDV são armazenados localmente no aparelho nesta versão.

Para uma versão nativa distribuída pela App Store, é necessário criar um projeto iOS e assinar/publicar com uma conta Apple Developer.
